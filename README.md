#  R STORE - Landing Page

Projeto desenvolvido para um cliente real (loja de roupas masculinas e fitness).

##  Sobre o Projeto
Este site foi criado com o objetivo de servir como uma **vitrine digital**, permitindo que os clientes visualizem os produtos e entrem em contato diretamente com a loja via WhatsApp ou Instagram.

A proposta é simples, funcional e focada em conversão.

---

##  Objetivo
- Divulgar a loja online
- Exibir produtos de forma organizada
- Facilitar o contato direto com o cliente

---

##  Funcionalidades
-  Layout responsivo (adaptado para celular e desktop)
-  Catálogo de produtos
-  Botão de compra via WhatsApp
-  Redirecionamento para Instagram
-  Navegação com scroll suave
-  Botões fixos de contato

---

##  Tecnologias Utilizadas
- HTML5
- CSS
